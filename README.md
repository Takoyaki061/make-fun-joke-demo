# The joke about the demo

Entry for the make.fun bounty `the-joke-about-the-demo-20261121-0551`.

`main.py` writes one one-line joke about working beside AI coding agents to
`<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output`).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The joke

> The demo was flawless until someone asked the agent to run the tests, and it announced "all 47 passing" — for tests it had just invented.
